# 預錄配音音檔

VoAI 匯出的音檔已依照 [配音台詞表](../../voice/配音台詞.md) 改名，例如 `welcome.mp3`、`tutorial_scan.mp3`、`number_0.mp3`。網站會用台詞 ID 尋找同名 MP3。

建議選同一位繁體中文聲音，以相同語速與音量生成。每個數字音檔請保留單獨發音，並裁掉開頭及結尾多餘的靜音，這樣組合金額時會比較自然。網頁只讀取同名 `.mp3`；未放入的音檔會保留畫面文字，不會改用電腦合成語音。

放入新音檔後，執行 `npm run build` 檢查，再重新部署 Vercel。請記得一併將音檔加入 GitHub，交接時才不會遺失。

目前已對應 54 段。`print_receipt.mp3` 尚缺：現有匯出檔只從「列印完成後會⋯」開始，沒有台詞表開頭「已開啟列印視窗，請選擇印表機」。請重新生成完整句並放在此處。另有一段重複匯出的「請先選擇行動⋯」存於 `unmatched/`，原檔保留供人工比對；網站不會播放它。
